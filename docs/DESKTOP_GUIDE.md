# Windows 桌面版使用说明（预览版）

适用版本：`v0.1.1-preview` 系列。LfSrcHarness 是本机桌面程序；打开软件本身
不需要 Docker、手动编辑配置文件或预装 Python。它仅用于合法、明确授权的安全工作。

## 下载安装

1. 在本仓库 [Releases](https://github.com/ZC-kf/LfSrcHarness/releases) 下载最新的
   `LfSrcHarness-Windows-Setup-preview.exe` 和同一版本的 `SHA256SUMS` 文件。
2. 对照校验文件中的 SHA-256 值核对安装包。此预览版尚未进行项目代码签名；
   如果下载来源、文件摘要或系统安全提示与预期不符，请先停止安装。
3. 运行安装向导，选择你自己的安装文件夹。安装程序会检查 64 位 Windows、
   .NET Framework 和 WebView2；缺少后两者时，会联网从微软官方下载并验证
   签名，完成后复查。若微软安装程序要求重启，重启后重新运行本安装包。
4. 安装完成后，从桌面或开始菜单的 `LfSrcHarness` 快捷方式启动。

安装包不包含离线大模型权重、原 Hacker Agent 本机副本或第三方扫描工具。可选工具
请按 [第三方来源清单](THIRD_PARTY.md) 从官方获取并自行遵守其许可。

## 第一次打开：先设置范围，再连接模型

桌面版会在本机启动只监听 `127.0.0.1` 的后台服务，软件窗口自动连接它；
通常无需输入 API Token。如果顶部显示“API 离线”，先关闭软件重新打开，
并检查是否被防火墙或安全软件拦截本机回环连接。

1. 打开左侧“设置”→“授权范围”。填写范围名称、已获授权的目标（每行一个）、
   每分钟请求上限，以及明确禁止的动作，点击“保存授权范围”。不要把未授权
   目标加入列表。当前界面只开放这些常用字段；时间窗和特权选项尚未做成桌面表单。
2. 打开左侧“模型”→“模型连接”。填写一个便于识别的配置名称，选择接口类型，
   再填写服务商、可信中转站或本地模型服务提供的接口地址和模型 ID。需要密钥
   的服务填入 API Key；不需要密钥的本地服务可留空。点击“保存模型配置”。
   密钥保存在 Windows 系统凭据库；列表只显示“已存密钥”，不会回显密钥原文。
3. 在“连接测试”选择配置，发送一条不含隐私信息的简短消息。测试消息会发往
   你填写的服务地址，可能产生服务商费用；收到回复才表示该连接可用。

“OpenAI 兼容”适用于提供相应聊天接口的国内外厂商、中转站和本地服务。
Anthropic、Gemini 和 Ollama 也有独立类型。请使用服务提供方公布的接口地址；
是否需要 API Key 由服务提供方决定，不要把密钥发到不信任的中转站。

## 当前界面能做什么

| 页面/按钮 | 预览版现状 |
|---|---|
| 总览、任务、运行 | 查看后台已有任务的数量、状态和最近记录；约每 5 秒刷新。 |
| 模型 | 新增、编辑、删除模型连接并发送测试消息。 |
| 设置 | 在桌面窗口内修改授权目标、速率和禁止动作。 |
| 审批 | 查看待处理项目；尚未提供桌面点击批准/拒绝。 |
| 全局急停 | 向本机后台发送全局停止请求；当前界面尚无恢复按钮，谨慎使用。 |
| 事件、证据、报告、节点 | 目前是展示/占位页，尚未提供完整检索、下载或真实节点健康状态。 |

当前预览版**尚未**提供桌面内新建任务、批量执行、审批处理和报告下载的完整操作流。
这些能力已有部分 CLI/API 接口，供高级用户参照 [接口使用说明](USAGE.md) 使用；
不要把占位页当作功能已经完成。后续版本会继续把这些操作迁入软件窗口。

## 数据、卸载与常见问题

- 软件安装目录由你选择；个人设置、任务数据库与运行记录默认保存在当前用户的
  `%LOCALAPPDATA%\LfSrcHarness`。卸载软件不会自动删除这些数据，以防误删。
- 模型保存后“连接测试”报错：先核对接口类型、完整地址、模型 ID、密钥权限，
  以及本机是否能访问该地址。保存成功不等于模型服务已通过真实请求验证。
- “任务”页空白：当前桌面版不会自动创建任务；没有通过后台接口提交的任务时，
  显示“暂无任务”是正常的。
- Docker Desktop 出错不妨碍打开核心桌面窗口；只有使用容器执行后端时才需要
  修复 Docker。不要为了解决桌面启动问题开启特权容器。
- 更新预览版前请备份用户数据。遇到缺失组件或安装中断，可按
  [安装指南](INSTALL.md) 的说明从官方渠道补齐后重新运行安装包。
